# Структура DynamicIsland

Проект собирается из `DynamicIsland.csproj` в корне. `App.xaml` и `MainWindow.xaml` остаются рядом с папкой `Fonts`, чтобы относительные адреса шрифтов WPF продолжили работать. C# файлы автоматически подхватываются из `src`. Части `MainWindow` используют одно пространство имён, поэтому могут находиться в разных папках.

| Папка | Что внутри |
| --- | --- |
| `src/App`, `src/Island` | Запуск, настройки, главное окно и его переходы |
| `src/Windows`, `src/SystemStatus` | Win32, автозапуск, системный статус |
| `src/Media` | Медиасеансы, управление плеером, звук и визуализация |
| `src/Lyrics` | Показ текста, анимация, поиск, сопоставление и кэш |
| `src/Weather` | Экран погоды, города, прогноз и жесты |
| `src/Api` | Провайдеры текстов, клиенты погоды, OBS, SoundCloud и обновлений |
| `src/Tools` | Таймер, полка, QR и управление записью |
| `src/UI`, `src/Animation` | Элементы интерфейса и анимация |
| `scripts`, `Gadgets/render.py` | Отдельные инструменты подготовки данных, картинок и скрипт для браузера |
| `publish` | Результат локальной сборки |

## Откуда берутся картинки

- **Погодные иконки в интерфейсе.** [Код погоды](../src/Weather/MainWindow.Weather.cs) выбирает символ по состоянию неба и времени суток. [Элемент Icon](../src/UI/Controls/Icon.cs) рисует этот символ как глиф из SF Pro, встроенного в приложение.
- **PNG из HyperOS.** Файлы в [Assets/Weather/HyperOS](../Assets/Weather/HyperOS/) лежат отдельно. Текущая версия их не читает и не встраивает в EXE, поэтому удаление файла с описанием их происхождения не влияет на погоду.
- **Устройства.** При сборке [проект](../DynamicIsland.csproj) встраивает PNG из [Gadgets](../Gadgets/). [Элемент Gadget](../src/UI/Controls/Gadget.cs) загружает нужный PNG из EXE по имени модели и показывает кадр из него. Скрипт `render.py` нужен для подготовки этих PNG в Blender.
- **Демонстрации.** Картинки в `docs` открываются на GitHub по относительным ссылкам из README. Их не загружает само приложение.
