# Медиаплееры Windows

DynamicIsland читает системные медиасеансы Windows, также известные как SMTC. От медиаплеера зависят название, исполнитель, обложка, состояние воспроизведения и доступность перемотки. Само приложение должно публиковать медиасеанс.

- Если доступен таймлайн, островок ведёт позицию от последнего достоверного отчёта по монотонным часам. При паузе позиция не продвигается.
- Для Telegram и Materialgram код умеет читать запасную полосу прогресса. Конечная длительность может появиться позже, когда её удастся оценить.
- Пустой медиасеанс браузера с названием `YouTube` может быть скрыт. Отдельный [браузерный скрипт](../scripts/browser/youtube-preview-media-guard.user.js) предназначен для превью YouTube. Сам островок его не запускает.
- Если позиция воспроизведения недоступна, синхронная подсветка по времени не работает. Для обычных текстов предусмотрен [режим без синхронизации](lyrics-sources.md).

Это описание поведения по коду. Совместимость с конкретными версиями Spotify, Яндекс Музыки, VK Музыки и других приложений зависит от их поддержки SMTC.

Реализация: [MediaService](../src/Media/MediaService.cs), [PlaybackClock](../src/Media/PlaybackClock.cs) и [PlayerBar](../src/Media/Visuals/PlayerBar.cs).
